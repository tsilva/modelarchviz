## PROJECT PURPOSE

ModelArchViz helps people learn and inspect neural-network architectures by connecting explorable model structures with the implementation code and source-paper context that define them.

## PROJECT REQUIREMENTS

- Users must be able to choose a supported model and inspect its architecture as an explorable hierarchy of meaningful components.
- Selecting an architecture component must reveal the corresponding implementation lines, keeping the architecture and code views synchronized.
- Each supported model must present architecture, implementation, and source-paper information that consistently identifies and explains the same model.
